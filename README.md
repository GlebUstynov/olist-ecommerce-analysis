# Brazilian E-Commerce Analysis

This project is based on the Brazilian E-Commerce Public Dataset by Olist.

I used this dataset to practice working with multiple related tables in Pandas and to build a small business analysis from raw e-commerce data.

## What I worked on

The analysis includes:

- loading and inspecting several CSV files
- cleaning date columns and checking missing values
- merging orders, customers, order items and products
- calculating total revenue and average order value
- comparing revenue by customer state
- analyzing monthly revenue
- finding the highest-spending customers
- comparing product categories by revenue and item count

## Main results

- 97.02% of orders were delivered successfully
- SP, RJ and MG generated more than half of total product revenue
- average order value was about $136
- November 2017 was the strongest month by revenue
- `beleza_saude`, `relogios_presentes` and `cama_mesa_banho` were the top categories by revenue

## Dataset

Brazilian E-Commerce Public Dataset by Olist.

Files used in this project:

- `olist_orders_dataset.csv`
- `olist_customers_dataset.csv`
- `olist_order_items_dataset.csv`
- `olist_products_dataset.csv`
